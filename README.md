# Network Exploration by Random Walks: A Large-Deviation Perspective

This repository contains the numerical simulation codes used in

> S. K. Upadhyay, T. Sandev, S. Kumar, and RK Singh,
> "Network Exploration by Random Walks: A Large-Deviation Perspective,"
> Chaos, Solitons \& Fractals 211, 118810 (2026).
> doi: https://doi.org/10.1016/j.chaos.2026.118810
## Overview

We study the exploration of complex networks by unbiased random walks from a large-deviation perspective. The code reproduces the numerical results presented in the paper.

## Requirements

The simulations were performed using:

* Python 3.x
* NumPy
* SciPy
* NetworkX
* Matplotlib
* Pandas

Install the required packages using:

bash
pip install -r requirements.txt
